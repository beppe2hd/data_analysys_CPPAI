# Data Analysis CPPAI

Corso di perfezionamento **Prompting e Tecnologie AI**  
Modulo di **Data Analysis** con Python e laboratorio su **Pandas**.

## Descrizione

Questo modulo introduce all’uso del linguaggio Python per l’analisi dei dati.  
In particolare, il corso presenta:

- le basi di Python;
- l’uso della libreria Pandas per la manipolazione e l’analisi dei dati;
- l’impiego di strumenti basati su agenti e LLM per l’automazione di alcuni processi di data analysis.

## Materiale didattico

Tutti i codici e gli esempi relativi alla parte di data analysis fanno riferimento al libro:

- Wes McKinney, *Python for Data Analysis, 3rd Edition*  
  [https://wesmckinney.com/book/](https://wesmckinney.com/book/)
